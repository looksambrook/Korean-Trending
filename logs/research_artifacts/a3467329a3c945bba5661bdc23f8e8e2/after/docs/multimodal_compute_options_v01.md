Runpod 수치는 [공식 GPU 가격표](https://www.runpod.io/pricing)의 Pods 행에서 읽었다. 표의 갱신 표시는 2026-09-13이다. [공식 Pods 과금 설명](https://docs.runpod.io/pods/pricing)은 온디맨드를 약정 없는 표준 시간 요금으로 설명하고 최종 최신 요금은 배포 화면에서 확인하도록 안내한다. 공개 페이지의 Community/Secure 선택 상태를 확정하지 않았으므로 위 숫자를 특정 지역·Cloud 종류의 보장 견적으로 쓰지 않는다.

## 표에 포함하지 않은 비용과 조건

- **스토리지:** Runpod은 별도 저장 요금을 명시한다. 예를 들어 실행 중 Container/Volume Disk는 $0.10/GB/월이며 Network Storage는 별도 요금표를 갖는다. 위 산술에는 저장비를 넣지 않았다. Lambda의 위 구성에는 표기된 로컬 SSD가 포함되어 있고, 별도 영속 저장·추가 저장의 비용은 이번 검토에서 확인하지 않았다. [Runpod 저장 요금](https://docs.runpod.io/pods/pricing), [Lambda 구성 표](https://lambda.ai/pricing).
- **세금:** Lambda는 해당 sales tax/VAT/GST 추가를 명시한다. Runpod의 적용 세금·한국 청구 조건은 이번에 확인한 본문에서 확정하지 못했다. 표에는 세금과 환전·결제 수수료를 합산하지 않았다. [Lambda 세금 표시](https://lambda.ai/pricing).
- **재고·지역:** Lambda는 선착순 접근을 설명한다. 어느 업체에서도 계정에 로그인하거나 지역별 재고를 조회하지 않았으므로 지금 원하는 GPU 1개를 확보할 수 있다고 보장하지 않는다. [Lambda Instances](https://lambda.ai/instances).
- **전체 실험 비용:** 전처리, 반복 훈련·추론, 공통 제작기, 데이터·체크포인트 저장, 실패/재시도, 사람 평가 비용은 별도다. 각 비용은 실제 설정과 측정 시간이 정해진 뒤 합산한다.

## 메모리 수치의 해석

기존 [모델 가능성 검토](multimodal_model_feasibility_v01.md)에 정리된 **40 GB LoRA**는 발행자의 Gemma3n 영상·음성 **분류 교육 예제** 설명이며 이 연구에서 잰 메모리가 아니다. **78.85 GB**는 Qwen3-Omni의 특정 15초 영상 설정에 대한 **이론상 최소 추론 메모리**였고 FT 메모리나 모든 설정의 80 GB 적합성을 뜻하지 않는다. 이번 가격 조사에서는 그 실험을 재현하거나 원문 수치를 새로 측정하지 않았다.

따라서 48 GB·80 GB는 가격을 비교할 자원 등급일 뿐이다. 모델·출력 형식·자료 길이·정밀도·학습 모듈을 정하고 제한된 실제 실행으로 피크 메모리와 소요 시간을 측정해야 선택할 수 있다. 현재 문서의 요금 곱셈으로 모델이 적재되거나 학습을 완료할 수 있다고 판단하지 않는다.
