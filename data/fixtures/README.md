# 소프트웨어 점검용 AI 합성 자료

이 디렉터리의 문장, 상황, src/run_smoke.py가 만드는 응답은 AI가 만든 형식 점검 자료다. 실제 유행어나 관찰 용례, 연구자가 독립 작성한 자료, 실제 모델 호출 결과, 사람 평가로 집계하지 않는다. provenance=ai_synthetic, record_origin=smoke_fixture, model_id=SMOKE_NO_MODEL로 구분한다.

이전 파일럿 입력과 실행 기록은 사용자 요청으로 삭제했다. 이 디렉터리는 보존한 코드의 테스트 입력이며, 과거 실험 결과의 백업이 아니다.
