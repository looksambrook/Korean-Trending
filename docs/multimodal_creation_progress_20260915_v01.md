# 멀티모달 밈 콘텐츠 제작 비교: 현재 진행 기록

기준일: 2026-09-15. 상태: **연구 준비 중, 실험 결과 없음**. 이 기록은 기존 발견 실험과 최신 콘텐츠 제작 비교를 구별하기 위한 것이다. 완료 목표는 실제 비교·독립 평가·재현 가능한 기록을 갖춰 논문 결과를 작성할 수 있는 상태다.

## 최신 범위

밈을 수집한 것으로 가정하고 그 자료를 콘텐츠 제작에 적용한다. 문맥/RAG와 실제 파인튜닝을 각각 실행해, 자주 바뀌는 밈의 반영과 제작 품질·갱신 비용을 비교한다. 입력은 텍스트·이미지·음성·영상을 포함할 수 있다. 특정 밈 형식만으로 제한하지 않지만, 실험 표본이 모든 밈을 대표한다고 미리 주장하지 않는다. 모델과 최종 제작물 형식은 미정이다.

## 검토에서 발견한 문제와 조치

- 과거 시점 제한과 사후 전처리 허용이 충돌할 수 있었다. 원자료·파생 표현·지식·연결·모델 버전의 실제 가용 시각을 명시하고, 후대 처리물을 과거 성능으로 소급하지 않도록 설계를 수정했다.
- 새 연결로 계열 그룹을 다시 만들면 과거 학습 항목이 평가 분할로 이동할 수 있다. 고정 분할을 계승하고 서로 다른 기존 분할을 연결하는 경우 차단하도록 데이터 준비 코드를 보완했다. `--prior-partition`으로 이전 스냅샷을 전달해야 하며 이를 자동 강제하는 연구 실행기는 아직 없다.
- 평가 계열의 과거 지원과 미래 제작 요청을 나누는 두 축 설계는 단순 train/dev/test 분할과 다르다. 현재 데이터 준비 코드가 그 연구 설계를 전부 구현했다고 표시하지 않는다.
- 입력 검증·해시 오류와 분할 충돌도 실패 원인과 재시도 이력을 남겨야 한다. 데이터 준비 실패를 모델 학습 실패나 생성 실패로 분류하지 않는다.

## 실제 실험을 시작하기 위한 정보

사용자에게 요청한 정보는 최종 제작물 형식, 실제 밈 자료의 위치·구성, 사용 가능한 GPU/서버와 연산 비용 상한이다. 그 답을 바탕으로 공통 기반 모델·제작기·학습 목표를 선택하고 **실제 RAG 출력과 실제 학습된 모델의 출력을 비교하는 개발 파일럿**으로 이어간다. 유료 실행이나 사람 평가 모집을 임의로 시작하지 않는다.

평가 계열·시간 분할, 학습·검색·제작 어댑터, 독립 평가 자료와 규모, 반복·통계 분석은 실제 본실험 전에 구현·검증·확정해야 한다. 미정 부분을 가짜 값으로 채워 실행 준비가 끝났다고 보고하지 않는다.
