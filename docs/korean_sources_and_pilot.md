원본 최초 공개일, 정체성 보존 규칙, 어떤 상황에나 적용 가능한지, 텍스트만으로 충분한지 등은 아직 확정하지 않았다. 웹 해설 글의 “예시”는 자연발생 사용 사례와 다르므로 관찰 지원 풀에 자동 편입하지 않았다. `context_paraphrase`는 AI가 출처 주변 문맥을 요약한 메타데이터이며 원문 인용과 구분한다. 원 작성물이 AI로 만들어졌는지까지 검증한 것은 아니다.

현재 근거는 수집·주석·직렬화 점검에 충분한 소수 후보지만 사람 평가의 일반화나 검정력에 충분한 표본이 아니다. 사용자 두 계열만 쓰면 형태 범위가 편중되므로 고정 인용 계열을 포함했다. 말투형·대화형의 충분한 실제 사례는 후속 수집 대상이다.

## 파일럿 편입 전 확인과 이용 범위

1. 지원 자료의 문자와 문맥을 원 페이지·원영상에서 재확인하고, 원영상은 타임스탬프와 공개일을 기록한다. “직접 원문”, “기사에 인용된 실제 사용”, “해설자의 예시”를 별도 열로 유지한다.
2. 동일 문서·원영상·미러·보도자료 전재를 연결하는 중복군을 확인한다. 공통 플랫폼·기관·저자 편향도 기록한다.
3. 외부 모델 입력과 재배포 조건은 아직 허가된 것으로 표시하지 않았다. 거제시 페이지는 공공누리 비영리·변경금지 조건, SBS는 AI학습 이용 금지, 정책 칼럼은 원작자 권리 표시가 있다. 공개 페이지라는 이유만으로 무제한 이용 허가로 해석하지 않는다. 조건 충족을 확인한 텍스트만 실행 풀로 승격하며, 나머지는 출처 메타데이터 또는 격리 후보로 유지한다.
4. 지원 풀을 먼저 고정한 뒤 자동 추출을 수행한다. 이 문서의 사람이 읽기 위한 추론·제안 라벨을 자동 레코드로 복사하지 않는다. 이후 평가 상황은 독립 작성하며 구조 추출 입력에 넣지 않는다.
