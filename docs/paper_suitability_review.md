# 논문 적합성 검토 — 2026-09-11

판단: **논문 주제로 적합하며, 통제실험 중심의 응용 NLP 연구로 진행할 가치가 있다. 현재 투고할 만한 실증 결과가 확보된 단계는 아니다.** 이는 연구 설계에 대한 판단이며 특정 학술지의 게재 가능성이나 채택 확률을 뜻하지 않는다.

## 추가 문헌 확인에 따른 판단 수정

명언의 고정/편집 부분 분해→재작성과 문화적 적응·의도 보존 평가는 직접 선행연구가 있다. [새 대조표](novelty_search_followup_v01.md)를 반영하면, 방법 구성요소 자체의 신규성을 내세우는 주장은 약하다. 동일 원자료·생성 모델·자동 레코드를 통제한 B1/B2/B3 결과, 다형태 적용 범위, 자동 추출 오류 분석에서 학술적 가치를 보여야 한다. 이 차별 후보의 가치는 실증 결과 없이 확정할 수 없다.

## 유지할 핵심 기여 후보

같은 LLM과 같은 원문·지원 용례를 사용할 때 자동으로 추출한 보존 요소·변경 가능 요소·사용 맥락 정보가 한국어 유행어 응용의 상황 적합성과 원 계열의 특징 보존에 미치는 영향을 검증한다. 서로 다른 표현 형태에서 자동 추출 오류가 어떤 생성 실패로 이어지는지 분석한다.

‘밈 정체성 보존’은 원 계열을 알아볼 수 있는 특징과 핵심 함의의 유지로 정의한다. 특정 인물이나 이용자의 정체성을 재구성한다는 의미와 구별한다. 문자열 일치만으로 측정하지 않는다.

## 심사상 중요한 약점과 대응

1. **추가 설명 또는 특정 서식의 효과에 그칠 가능성.** B3−B1은 자동 추출 단계와 정보 추가를 포함한 전체 방법 차이다. B3−B2는 같은 자동 사실을 사용한 두 렌더링 간 차이다. B2를 일부러 부자연스럽게 만들지 않도록 개발 자료에서 읽기 가능성을 점검하고, 내용 대응과 토큰 길이를 기록한다. 추출 비용도 공개한다. 특정 렌더링에서의 결과를 모든 구조화 프롬프트로 일반화하지 않는다.
2. **독립된 자료의 부족.** 기존 3계열은 파일럿 준비 자료이며 추가 2계열은 미편입 개발 후보다. 합계 5계열 후보·13관찰·12문서는 본실험 표본이 아니다. 원형·출처 의존성과 표현 다양성을 검토하고 개발과 분리된 시험 계열을 확보해야 한다. 같은 계열에서 생성문을 많이 만들었다고 독립 표본이 늘어나는 것은 아니다.
3. **사람 평가의 타당성 미확인.** 상황 적합성과 정체성 보존을 평가자가 구별하는지 파일럿으로 확인한다. 원자료를 제시하기 전 상황 평가와 제시 후 정체성 평가를 분리한다. 20대 중심 표집에서 친숙도·모집 경로·평가자 관계를 기록하고, 연구자 자체 점검과 독립 평가를 구분한다.

## 결과에 따른 정직한 해석 — 아직 관찰된 결과가 아님

- B3가 B1과 B2보다 나은 결과: 정보 명시화와 해당 필드형 표현의 이점을 각각 검토할 근거가 될 수 있다. 두 주요 지표를 모두 개선했다고 쓰려면 각각의 결과가 뒷받침해야 한다.
- B2와 B3가 B1보다 나으나 둘의 차이가 불분명한 결과: 자동 정보 제공의 이점을 검토할 수 있지만 필드형의 우수성은 주장하지 않는다. 차이의 비유의성만으로 동등성을 선언하지 않는다.
- 개선이 불분명하거나 일부 유형에서 악화한 결과: 효과의 불확실성과 자동 추출 오류·유형별 한계를 보고한다. 표본이 작아서 구분하지 못한 것과 충분한 정밀도로 실용적 이점이 없음을 확인한 것을 구별한다. 부정적 결과만으로 논문 가치나 게재를 보장할 수는 없다.

## 현재 준비 상태와 다음 판단 시점

문헌 검토, 주석·분할·평가 지침, B1/B2/B3 요청 생성 코드와 합성 자료를 이용한 절차 점검은 준비되어 있다. 실제 자동 추출 레코드와 사람 평가 점수는 없다. 실행 어댑터와 로컬 평가 앱을 포함한 회귀 테스트 59개가 통과했다. 이는 구현 점검이며 연구 효과를 입증하지 않는다. 브라우저 시각 검증과 실제 평가 운영은 남아 있다.

2026년 11월 말 투고를 지향하는 운영 제안에서는 먼저 검증 가능한 소수 개발 계열로 추출 근거성, 평가 가능성, 작업 시간을 점검한다. 이후 평가자·자료 확보 가능성을 근거로 본실험 범위를 정하고 시험 계열·프롬프트·분석 계획을 잠근다. 검색과 서비스 기능 확장은 별도 과제로 둔다. 본실험 표본 수를 KCI의 공식 조건으로 제시하지 않는다.

범위와 일정 판단의 핵심 미정 사항은 정확한 평가 참여 수(연구자 제외6명이상 확보 가능은 확인), 기관의 사람 평가 절차, API 예산·모델, 투고 학술지다. 현재 연구를 계속할 근거는 있으나 12월 전 투고 완료 여부는 이 자원과 실제 파일럿에서 확인할 자료 품질에 달려 있다.
