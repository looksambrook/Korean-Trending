## 본문 대조 결과

### 이대규·이찬규(2023): 가장 가까우나 본문 대조 미완료

공개 초록은 표제어 1,035개·활용형 1,654개 사전과 온라인 자료의 출현 비율 분석을 보고한다. 문형 작업, 관용표현 대응, 비윤리성, 지속적 구축도 다룬다. 따라서 **국내 밈 데이터·유형·의사소통 지원이라는 기여를 새로 주장할 수 없다.** [KCI 초록](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003044747)

남은 확인: §3 데이터 구축, §4 유용성 검증, §5 시스템 사전 검토의 실제 표본·코더·실험·출력. 이 절 제목은 KISS 목차에서 확인한 것이며 본문 내용은 미확인이다. 발행기관 공개 자료실은 웹 도구 오류와 직접 요청 타임아웃을 반환했다. 도서관 구독 또는 저자가 제공하는 합법적 사본으로 보완할 수 있으며, 연락·구매는 수행하지 않았다.

## 본 연구에 반영할 판단

다음은 위 논문들의 결론을 복제한 것이 아니라 본 연구를 위한 설계 판단이다.

1. ‘유행어 분류 체계 구축’ 단독을 주 기여로 삼지 않는다. 주장은 **정보 내용이 동일한 서술형/필드형 표현의 효과와 자동 추출 오류의 전파**에 한정하고 결과로 검증한다.
2. 계열·용례·응용 연산을 서로 다른 단위로 둔다. 하나의 계열에 복수 재생산 방식이 관찰되거나 변경 요소가 없을 수 있다. 허용되는 변형은 관찰 근거와 불확실성을 함께 기록한다.
3. 생성 평가의 정체성 보존, 주석의 형태 분류, 인물·사용자 정체성 개입을 별도 개념으로 정의한다. 이름이 비슷하다는 이유로 선행 지표를 그대로 채택하지 않는다.
4. 사람 평가는 독립 상황 적합성·정체성 지표로 유지한다. 코더 합의본과 최초 독립 판정을 모두 보존하며, 자동 레코드 결과와 사람 검토 결과를 혼합하지 않는다.
5. 이대규·이찬규(2023) 본문 입수 전에는 국내 최초·기존 연구 부재·해당 연구보다 성능 우위라는 주장을 보류한다. 현재 확인된 차이도 연구 단위와 실험 구성의 차이이며 게재 가능성의 증거는 아니다.
