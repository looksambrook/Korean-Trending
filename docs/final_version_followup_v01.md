# 국제 논문 게재본 대조 v0.1

확인일 2026-09-11. 웹 도구의 크기 제한으로 읽지 못했던 공개 ACL PDF 2편을 로컬에 내려받아 관련 절을 읽었다. 이는 **선택 절의 내용 대조**이며 전문의 문장 단위 동일성 검사나 실험 재현이 아니다. [확보·열람 기록](../data/literature/final_version_followup_v01.json)에 URL, 파일 해시, PDF 페이지와 제한을 남긴다. 기존 저자판 열람 기록은 보존한다.

| 문헌 | 새 확인 범위 | 기존 설명에 미치는 영향 |
|---|---|---|
| [Social Meme-ing](https://aclanthology.org/2024.naacl-long.166/) | ACL 현재 PDF §2–4, §11. PDF 2–5·9쪽 | 시각 템플릿/의미 기능 분리와 사람의 의미·시각 유사성 평가라는 기존 설명을 확인. 최신 PDF는 공통 평가자의 모델 간 판단과 평가 풀 설명을 더 명시한다. |
| [A Template Is All You Meme](https://aclanthology.org/2025.naacl-long.525/) | 게재 PDF §3–5.1.1, Limitations. PDF 3–8·10쪽의 해당 본문 | 지식베이스·템플릿 매칭·TSplit이라는 기존 설명을 확인. **원래 시험셋을 유지한 다운샘플링**과 **시험셋까지 새로 나눈 실험**은 별개다. 모든 결과를 완전히 동일한 시험 조건으로 비교한 것처럼 인용하지 않는다. |

Social Meme-ing의 기존 arXiv v1 §2–4와 현재 ACL PDF를 대조했다. 기존 방법 요지는 유지되지만 최신본에 평가 설명과 Limitations가 있으므로 이후 인용은 확보한 공식 PDF의 절을 사용한다. ACL 서지는 3005–3024쪽이며 페이지는 Original/v2 PDF를 별도로 연결한다. 내려받은 기본 PDF는 21쪽이므로 문서 내 위치는 **PDF 페이지 번호**로 기록한다. 이를 서지 쪽수로 재계산하거나 원판과 바이트가 같다고 주장하지 않는다.

A Template의 arXiv v2 §5.1–5.1.1과 게재본의 해당 절은 위 두 실험 구성을 모두 구별한다. 템플릿/비템플릿 처리와 분할 개념의 선행성은 분명하다. 저자들의 이미지 매칭 기준을 한국어 텍스트 계열의 완전한 정답으로 옮기지는 않는다.

FormatSpread의 OpenReview forum/PDF는 브라우저 확인 화면으로 본문·결정에 접근하지 못했다. 따라서 기존 arXiv camera-ready 판의 독해 범위를 유지한다. 다른 논문의 참고문헌이나 검색 색인만으로 공식 최종판 전체를 확인했다고 올리지 않았다.

문헌의 성능 수치는 새로 옮기지 않았다. 신규 직접 중복 문헌은 [별도 대조](novelty_search_followup_v01.md)에 있다. 이 검토로 한국어 생성 효과가 검증되거나 본 연구의 독창성이 확정되지는 않는다.
