## 실제 실패에서 수정한 기능

첫 자동 실행 `58a8828abbd94b38a49a1f33401fc73c`는 공개 GET 23회로 실행됐지만 다음 문제가 있었다. 원본과 당시 결과를 덮어쓰지 않았다.

1. ‘그 효과음’이라는 불명확한 지시 표현을 공유하는 자료들을 한 계열로 연결했다. 같은 소리를 가리킨다는 근거가 없어 자동 연결 근거를 취소하고 `needs_evidence`로 낮췄다. 이후 기본 선정에서는 이런 일반 지시 표현을 우선 검색하지 않는다.
2. ‘갈테야 갈테야’의 실제 변형을 모으고도 명시적인 ‘밈’ 표시가 없다는 이유로 보류했다. 관찰된 반복 위치와 중간 내용 변화도 비교하도록 개선했다. 특정 유행어를 하드코딩한 목록은 사용하지 않았다.
3. 검색 결과의 `description_snippet`을 읽지 않아 영어 제목의 관련 제작자 영상을 누락했다. 스니펫을 탐색 단서로 읽고 원문 페이지를 별도 확인하도록 고쳤다.

[동일 실제 자료에서의 오류 교정 기록](../data/research/meme_finder_actual_error_analysis_v01.json)은 개발 사례 분석이다. 독립 정답 기반 정확도·재현율이 아니다. 그 기록을 만드는 과정의 ID 비교 오류와 명시적 재시도도 장부에 남겼다.

## 식별과 모델 이해의 현재 상태

`meme_identify.py`는 입력 표현을 발견된 실제 용례의 구조·문구와 연결해 출처와 저장된 쓰임을 반환한다. 최종 결과에 연결한 [AI 합성 반복문](../data/derived/meme_finder_delivery_20260915_v01/identify_repeated_ai_synthetic.json)은 잠정 연결됐고, [무관한 AI 합성 문장](../data/derived/meme_finder_delivery_20260915_v01/identify_unknown_ai_synthetic.json)은 `unknown`이었다. 이 두 건을 실제 수집 자료나 의미 이해 정확도 평가로 세지 않는다.

선택적인 `meme_local_understanding.py`는 로컬 모델 실행, U0/U1 동일 근거, 시간 제한, 응답·토큰·비용 기록을 연결했다. 실제 최종 자료에서는 ‘갈테야’ 계열의 같은 원문 4건으로 U0 2,116토큰, U1 2,978토큰을 준비했다. [실행 기록](../data/derived/meme_local_understanding_20260915_final/manifest.json)의 상태는 `blocked_local_resources`다. 당시 가용 메모리 약 2.28 GiB가 보수적 필요량 약 14.65 GiB보다 작아 모델 가중치를 로드하지 않았다. 실제 모델 추론·응답·학습은 0이다. 수집·규칙 기반 발견에는 이 모델이나 서버가 필요하지 않다.

## 코드 확인과 연구 범위

[변경 모듈 회귀 확인](../logs/meme_finder_final_tests_v01.json)은 합성 입력 24개 테스트가 통과했다. 뉴스 반복, 복제 제목, 불명확한 지시 표현, 스니펫 누락, 한글 정규화, 시점 제한, 보고서 이스케이프, 모델 자원 부족을 성공으로 반환하지 않는 동작 등을 확인했다. 소프트웨어 테스트 수를 밈 발견 성능으로 표현하지 않는다.

최종 실제 실행 이후에는 CLI의 선택 모델 실패 상태 전달, 분해형 한글의 원문 연결, 보고서 표시를 수정했다. 같은 실제 결과를 쓰는 후속 확인과 보고서 렌더링은 별도 실행으로 기록했다. 데이터 수집·자동 계열화 결과를 새로 수집한 것처럼 소급하지 않았다.

현재 제공하는 것은 실행 가능한 YouTube 텍스트 밈 탐색기다. 영상·음성 이해, 플랫폼 전체의 유행 순위, 독립 정답 평가, 놓친 밈의 전체 재현율, 모델 이해 성능, 다중 플랫폼 연결과 논문 연구 전체는 완료했다고 주장하지 않는다. 다중 플랫폼 연구 목표와 D0/D1 × U0/U1 계획은 유지한다.
