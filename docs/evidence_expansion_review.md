첫 후보는 한 문구를 앞 상황 뒤에 붙이는 대본과 어휘가 달라진 제목을 함께 검토할 수 있다. 둘째 후보는 제목 사용과 질문에 응답이 이어지는 보도 사례를 대비할 수 있다. 이는 자료를 선택한 이유이며 확정 유형, 슬롯, 사용 가능 규칙의 정답이 아니다. 기존 인용문 계열과 함께 텍스트 사용 방식을 넓히되 모든 사례를 빈칸 치환으로 표현하지 않는다.

공식 기관·방송사 자료는 실제 게시 여부를 확인하기 쉽지만 홍보·편집 문구에 편중된다. 따라서 이 5계열만으로 20대 일상 언어 사용을 대표한다고 쓰지 않는다. 대상 화자가 언급되었다는 이유만으로 친밀한 관계·허용된 농담·실제 발화 톤을 단정하지 않는다. MBTI에 관한 출처의 설명은 해당 게시물의 표현 관습을 관찰한 것이며 성격 유형의 과학적 타당성을 검증한 결과가 아니다.

## 중복과 확인 수준

- 법무부 HTML 내부의 반복 대본은 하나의 사용 사건으로 묶었다.
- JTBC 추천 목록·다른 회차 페이지·외부 재게시에서 반복된 클립 제목은 클립 ID별 한 사건으로 묶었다. 대상 VOD 페이지에 직접 들어가 제목과 등록일을 확인했다.
- iMBC 2개 문서는 같은 플랫폼이지만 필자와 대상 프로그램·방송일이 다르다. 기사 수 2개가 서로 다른 출판 플랫폼 2개를 뜻하지 않는다.
- 같은 JTBC 프로그램이 서로 다른 후보 계열에 등장한다. 본실험에서는 계열 분할과 별개로 제작자·플랫폼 편중도 함께 검토할 필요가 있다.
- 원형의 최초 발화·정확한 기원은 이번 확인 범위에 포함되지 않는다. 제목 관찰을 음성·동작 관찰로 승격하지 않았다.

## 보류한 후보

`참 쉽죠/쉽쥬`는 안내 문구 사용을 여러 곳에서 찾았으나 일반적인 수사의문과 특정 밈 인용을 구분할 근거가 충분하지 않았다. 서로 다른 종결 표현을 하나의 계열로 묶는 근거도 아직 없다. 독립 계열을 하나 더 만들기 위해 강제로 편입하지 않았다.

서울동행 멘토링 홍보는 서울시 검색 색인과 외부 모집 재게시에서 발견했지만 원페이지가 리디렉션 오류로 직접 열리지 않았다. 철도산업정보센터의 관광 글은 검색 결과와 직접 열기 텍스트가 일치하는지 확인하지 못했다. 두 후보 모두 보류 파일에 위치만 남겼다.

## 이용 조건과 보관 범위

각 출처의 짧은 문구·직접 문맥·URL·게시일·필자 또는 기관명·변경 내역만 기록했다. 전체 기사·전체 대본·이미지·음원·영상은 저장하지 않았다. 신규 6개 출처별 제목과 두 인용 필드의 공백 기준 어절 합계는 각각 23·12·24·18·16·22개다. 이 집계는 저작권 허용 판정이 아니며 내용 최소화 점검이다.

법무부 HTML에는 공공누리 1~4유형 안내가 동시에 추출되어 실제 선택 유형을 판단하지 못했다. iMBC에는 AI학습을 포함한 무단 이용 금지 문구가 있다. 금융위·JTBC 개별 자료의 외부 모델 전송·재배포 허락은 확인하지 못했다. 따라서 현재는 출처 품질 검토 자료로 보존하고, 이용 조건을 확인했다는 사실과 실험 전송·공개가 승인되었다는 사실을 구분한다. 이 문서는 법적 이용 여부를 판정하지 않는다.

## 다음 실행 순서

1. 원문 인용·부분 발췌·정규화·문서/사건 그룹을 다른 검토자가 대조한다. 관계·유형·보존 규칙을 추가하는 일과 문자의 검증을 분리한다.
2. `context_updates`의 해양레저팀 정정과 직접 인용 문맥을 검토한 뒤 기존 지원 파일의 새 버전을 만든다. 원파일과 요청 해시는 보존한다.
3. 새 계열의 텍스트 과제 적합성·상위 파생 관계·독립 용례 수를 검토한다. 모든 후보는 dev로 남긴다. 본실험 시험 계열로 재사용하지 않는다.
4. 이용 범위가 정해진 지원 자료만 추출 요청에 포함한다. 자동 구조 추출에는 원문 후보·지원 텍스트·직접 문맥만 제공하고, 이 검토 문서의 해석이나 최종 평가 상황은 넣지 않는다.
5. 생성 파일럿은 지원 자료와 별개로 작성·검토한 개발 상황과 함께 진행한다. 시험 상황·정답·점수는 프롬프트나 출처 선택에 사용하지 않는다.

이 단계의 성과는 출처 검증과 입력 근거의 보강이다. 모델 성능 향상, 자동 추출 정확도, 사람 평가 일치도에 관한 결과는 아직 없다.
