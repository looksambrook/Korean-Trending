## 확인하지 못한 범위

한국어 자동 자막의 공개 endpoint에 한 차례 요청했으나 HTTP 200과 빈 본문이 반환되었다. 자막 문장은 읽지 못했고 음성도 듣지 않았다. 따라서 ‘감옥에서 누가 돌아왔게’의 실제 발화, 전후 대사, 억양, 영상 내 시각, 전사 정확성은 여전히 미확인이다. 빈 응답만으로 자막이 존재하지 않는다거나 영상 접근이 금지되었다고 결론 내리지 않는다.

거제 야호 계열의 특정 원영상 식별은 이번 확인에서 진전되지 않았다. 기존 기사의 채널명과 관계없는 영상을 대상 원영상으로 채택하지 않았다.

## 기록과 데이터 처리

- [영상 메타데이터 관찰 JSON](../data/evidence/original_video_metadata_probe_v02.json): 요청 URL, HTTP 상태, 선택한 공개 메타데이터, 읽은 본문의 크기와 SHA-256을 기록했다.
- [자막 요청 결과 JSON](../data/evidence/original_caption_probe_v02.json): 자동 자막 유형과 언어, 빈 응답, 직접 음성·자막·원구절 미확인 상태를 기록했다.

전체 watch HTML, 쿠키, 서명된 미디어·자막 URL, 영상·음성 파일은 이 관찰 자료에 저장하지 않았다. 해시는 읽은 응답을 식별할 뿐 본문 전체를 보관하거나 진위를 인증했다는 뜻이 아니다.

기존 기사가 가리킨 동일 영상의 메타데이터 대조이므로 신규 독립 사용 수는 **0**이다. 지원 7개·개발 계열 3개·상황 6개와 프롬프트·실행 설정을 변경하지 않았다. `original_audio_video_directly_verified`와 외부 사용 확인 플래그도 그대로 유지한다. 직접 발화 검증이나 이용 허가가 이루어진 것으로 승격하지 않는다.
