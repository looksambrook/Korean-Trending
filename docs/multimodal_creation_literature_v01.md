## 이번 프로토콜에서의 적용

다음은 위 논문의 결과가 아니라 이 프로젝트의 **설계 제안**이다.

1. CR(RAG)과 CF(미세조정)에 같은 시점의 원자료·지식·제작 예시 풀을 제공한다. 검색으로 실제 보인 자료와 학습에서 반복 노출된 자료의 양은 따로 기록한다.
2. 콘텐츠 제작 요청은 별도로 잠그고, 입력 지원 자료와 평가용 목표·해설을 분리한다. 자동 생성한 목표나 모델 자기 점수를 독립 정답으로 쓰지 않는다.
3. 입력의 native 미디어 접근, 대리 표현, 출력 계획과 실제 완성 파일을 구별한다. 모델이 모든 모달리티를 입력받는다는 설명만으로 영상·음성·이미지 생성이 모두 가능하다고 판단하지 않는다.
4. 시간별 갱신 후 새 용법 적용과 기존 유효 용법의 유지, 제작 실패와 지원 불가 사례, 전처리·학습·검색·제작·검수 비용을 함께 기록한다.

자료 형식·목표 출력·모델이 정해지면 그 조합의 학습 방법과 제작 평가 문헌을 추가로 검토해야 한다. 현재 확인한 네 원문만으로 이 프로젝트가 최초 연구라거나 논문 게재가 가능하다고 보장하지 않는다.
