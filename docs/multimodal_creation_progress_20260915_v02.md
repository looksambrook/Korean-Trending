## 실제 실험에 남은 조건

이번 콘텐츠 제작 비교에서 **실험 모델 추론 0회, 학습 0회, 독립 사람 평가 0회**다. 학습 체크포인트·완성 콘텐츠·품질 점수·실측 갱신 비용은 없다.

사용자에게 요청한 **최종 제작물 형식, 실제 밈 자료 위치·구성, GPU·연산 예산 범위**는 아직 확인되지 않았다. 그 범위가 정해져야 공통 모델과 제작기를 선택하고 자료를 적재해 실제 RAG·FT 개발 파일럿을 실행할 수 있다. 별도의 사람 평가자·규모·보상도 실제 모집 전에 정한다.

선택한 모델의 입력 포장·검색·학습·제작 실행기, 모든 필요한 코덱의 실제 자료 검사, 모델/인덱스/체크포인트의 시간 조건, 독립 평가와 반복 실험은 여전히 남아 있다. 준비 코드가 통과했다는 이유로 이 조건을 충족했다고 표시하지 않는다. 연구 설정의 모델·출력·예산·평가자·주과제 선택은 계속 미정이고 `execution_ready:false`다.
