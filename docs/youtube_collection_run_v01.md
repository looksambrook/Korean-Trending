# YouTube 실제 수집과 후보 발견 — 2026-09-15

이전 조사·계획서 작성만으로 작업을 완료했다고 한 판단은 잘못이었다. 이 기록은 실제 HTTP 수집과 작동하는 코드에 관한 후속 기록이다. 이전 원본·실패 로그·개발 중 결과를 보존했다. 최신 연구 목표는 여전히 다중 플랫폼 발견부터 모델 식별·이해까지다.

## 실제로 작동한 경로

**API 키 없이 공식 채널 Atom 피드를 로컬에서 받아 제목·설명 후보를 추출할 수 있었다.** 침착맨·빠니보틀·TEO 3개 채널에 각각 1회 GET하여 HTTP 200 응답 3개, 실제 영상 메타데이터 45건을 저장했다. 피드마다 15개가 왔다는 것은 이번 응답의 관측값이지 공식 제공량 보장이 아니다.

공식 YouTube 문서에 피드 주소와 Atom 예시가 있다. 문서가 설명하는 push callback 구독과 이번 단발 GET은 구분한다. 단발 수집과 로컬 보고서에는 서버가 필요하지 않았다. [공식 Push Notifications 문서](https://developers.google.com/youtube/v3/guides/push_notifications)

채널은 접근 가능성을 시험하기 위해 채널명으로 골랐다. 특정 밈 이름을 최초 수집 조건으로 넣지 않았으나, 대표성 있는 표본이나 무작위 표본도 아니다. 채널별 피드가 포함하는 게시 기간이 크게 다르므로 빈도를 플랫폼 전체 유행이나 증가율로 해석하지 않는다.

## 작동하게 만든 개선

- 영상당 제목·설명을 하나의 관측 문서로 보존한다. 같은 영상의 제목·설명을 서로 다른 사용례로 세지 않는다.
- 제목·설명·줄·URL 경계를 넘어 가짜 어구를 결합하지 않는다.
- 연락처, 제작 안내, 같은 채널의 반복 설명을 후보 지지에서 억제하고 `suppressed.jsonl`에 원문·사유를 남긴다. 억제는 자동 규칙이며 비밈 정답 판정이 아니다.
- 한 단어 해시태그도 후보로 삼는다. 특정 밈 이름을 코드에 넣지 않았다.
- 영상 수·채널 수·제목 지지·해시태그 지지를 따로 보여준다. 독립 사용 수는 확인 전까지 미상이다.
- D0는 공통 전처리 후 문서 빈도와 영상 수로만 순위를 정한다. D1의 문맥 우선 순위와 잠정 변형 연결은 별도로 표시한다.
- 전체 관측 문서를 보고서에서 검색할 수 있어 후보로 뽑힌 것만 살펴보는 제약을 줄였다.

## 실제 사례와 남은 오류

`실례카겔`은 초기 원문에 있었지만 첫 무필터 추출 결과에는 없었다. 제목·해시태그 처리 개선 후 같은 자료에서 D0 35위, D1 초기 구현 13위로 나왔다. 이는 개발 자료에서 확인한 기능 수정 결과이며, 독립 시험 자료의 성능 향상을 뜻하지 않는다.

근거는 침착맨 채널의 [실리카겔 실례카겔](https://www.youtube.com/watch?v=TBqvX5m2qlI) 제목·해시태그와 [침착맨을 만난 밴드 실리카겔](https://www.youtube.com/watch?v=yN_GxazmPT8) 설명의 자료 출처 표기다. 두 영상은 같은 채널에 있으므로 독립적인 밈 변형 2건이라고 세지 않는다. 이후 이 표현을 지정한 검색은 사후 근거 확장이다. [확장 근거와 열람 범위](youtube_phrase_evidence_v01.md)

후속 코드 수집에서는 스낵타운의 [NO PAIN](https://www.youtube.com/watch?v=Q9hDqYvhrOU) 전체 설명을 읽었다. 이 설명은 Silica Gel을 대상으로 한 Sillaeca Gel의 패러디 공연이라는 관계를 명시한다. [BIG VOID](https://www.youtube.com/watch?v=jxw1Cudx5lA) 설명은 같은 프로젝트의 다음 회차를 소개한다. 따라서 이 사례는 **이름 없이 채널 자료 관측→후보 처리 개선→표현 검색→원 제작자의 설명으로 의미 관계 확인**까지 실제로 연결했다. 원 제작자의 자기소개를 읽은 것이며 최초 창작자·최초 유행 시점·전국적 인기 증가를 독립 입증한 결과는 아니다.

검색 20건은 새로운 밈 20개가 아니다. 원래 피드와 겹치는 영상이 있고, 관련 밴드에 관한 결과도 섞였다. 후속 영상 페이지 3건은 이 검색 결과의 일부를 더 자세히 읽은 것이므로 세 수량을 합산하지 않는다.

상위에는 `왕자와 거지`, `짐쌀라비움`, 인명·일반어·광고 관련 표현도 남는다. 프로그램명 반복과 밈 사용을 구별하는 단계가 더 필요하다. 사람 정답 자료가 없으므로 정확도·재현율·가짜 후보 총수·누락된 밈 총수·계열 연결 오류율은 산출하지 않았다. 현재 보고서는 이런 검토를 가능하게 하는 도구이며 밈 이해를 완성한 시스템이라고 제시하지 않는다.
