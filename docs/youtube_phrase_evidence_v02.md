# 실제 공개 검색 원문 기반 실례카겔 검토 v0.2

이 버전은 [실제 수집 manifest](../data/collected/youtube_search_expansion_20260915_v01/fbfd5698ba994f959bb750623713d378/manifest.json)와 저장된 검색 HTML·관찰 자료만 검토했다. 이전 v0.1을 수정하지 않았다. **실례카겔이라는 명칭이 공연·비교·소개 제목에서 반복된다는 실제 메타데이터 근거를 확보했다.** 영상 내용과 독립 변형, 모델의 이해 성능까지 검증한 것은 아니다.

수집 코드는 공개 YouTube 검색 페이지에 HTTP 요청 1회를 보내 1,288,581바이트의 HTML과 최대 20개 결과 카드를 저장했다. 로컬 원문의 SHA-256이 manifest와 같고, 20개 영상 ID가 원문에 들어 있음을 확인했다. v0.1의 원페이지 열기 7건 실패는 **웹 도구의 watch 페이지 접근 경로**에 한정된다. 이번 공개 HTTP 검색 페이지 성공과 접근 범위가 다르다.

## 잘못 채택할 수 있는 검색 결과

[기타 관련 영상](https://www.youtube.com/watch?v=U2iEtbZAqDg)은 실리카겔 기타에 관한 제목이며 후보 명칭이 없다. [음감·인물 관련 영상](https://www.youtube.com/watch?v=VlzD_PgcB-c)도 후보 표현을 제공하지 않는다. 둘 다 실제 검색 결과지만, 그 사실만으로 후보 밈의 양성 근거로 채택하면 오탐 위험이 있다. **가짜 영상이나 확정 비밈이라고 판정하지 않았다.** 실제 내용에 후보가 있을 수도 있으므로 비밈 정답은 별도 검토해야 한다.

반대로 [비교형 표현이 있는 영상](https://www.youtube.com/watch?v=mdZyignFp3U)은 정확한 후보 이름이 없어도 관련 패러디일 수 있다. 정확 문자열이 없다고 음성 정답으로 처리하면 누락을 만들 수 있다. 검색 결과와 밈 판정, 문자열 매칭과 계열 판정을 분리해야 하는 사례다.

20개 카드에서 NFC 유니코드 정규화 후 정확 문구가 들어 있는 제목·설명 조각은 12개, 별도 표면형 변형 후보는 1개, 나머지 7개는 현재 텍스트만으로 해당 표현의 근거가 부족하다. **12/20은 정밀도가 아니다.** 검색어로 이미 표현을 지정했고 독립 정답도 없으므로 정밀도·재현율·유행 정도·전체 밈 규모를 계산하지 않는다. 채널 ID가 확인된 두 카드는 같은 채널이며, 다른 18개 카드는 이 결과만으로 게시자 독립성을 확인할 수 없다.

## 시간·버전과 기록

검색 수신 시각은 `2026-09-14T18:28:27.234807+00:00`, 수집 종료는 `18:28:28.861779 UTC`이다. 검색 카드의 상대 게시일은 정확한 게시 시각으로 바꾸지 않았다. 모든 20개 자료는 현재 정확한 과거 게시 시각 분석에 부적격으로 표시되어 있다. 이번 해석·연결의 생성 시점은 [구조화 기록](../data/research/youtube_phrase_enrichment_v02.json)의 `knowledge_available_at`이며, 원래 T인 `18:20:52.811337 UTC` 입력에 넣지 않는다.

원래 사전 명칭 없는 RSS 수집 → 개발 중 원문 검토에서 문구 선택 → 해시태그 처리 보정 → 이름을 사용한 공개 검색이라는 경로를 유지한다. 이 사례를 보고 개선한 코드를 같은 사례의 독립 성능으로 평가하지 않는다. v0.1의 초기 후보 누락 기록도 보존한다.

검토 로그는 `dc58e776600548c89d58243e477bbfcb`이다. 입력을 먼저 확인한 뒤 구조화 검토 전에 등록했으므로 눈가림된 사전 평가가 아니다. 로컬 검토 중 콘솔의 한글 표시 오류는 UTF-8로 다시 읽어 해결했으며 실제 원자료·등록 문구는 손상되지 않았다. 새 네트워크·모델 API 호출은 없고 사람 검수는 수행하지 않았다. 사람 시간·에이전트 토큰 비용은 계측하지 않아 `null`이다.
